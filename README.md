\# Hello World CI Pipeline



\## Project Overview

This project demonstrates a simple Continuous Integration (CI) pipeline using GitHub Actions.



\## Objective

To automate the Build, Test, and Deploy stages whenever a pull request is created targeting the main branch.



\## Project Files

\- `hello.sh` - Prints Hello, world!

\- `.github/workflows/ci.yaml` - Defines the GitHub Actions workflow.

\- `README.md` - Describes the project.



\## Pipeline Stages

1\. Build: Runs the Hello World script.

2\. Test: Prints a test success message.

3\. Deploy: Prints a deployment success message.



\## Trigger

The workflow runs when a pull request targets the main branch.



\## Expected Output

\- Hello, world!

\- Test successful

\- Deploy successful
